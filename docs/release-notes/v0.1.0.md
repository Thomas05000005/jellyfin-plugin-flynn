# Flynn v0.1.0

The first build you can install. It does one useful thing and is honest about the rest.

## What you get

**Storage.** A card showing how much your libraries hold and how much room is left on the tightest
device, measured by a task that runs nightly at 03:15. Jellyfin's own dashboard shows your library
paths but neither their size nor the free space behind them, which is the gap this fills.

The first reading appears after the first sweep. Until then the card says so rather than showing
zero — a panel that admits it has nothing beats one showing figures it made up.

You can run it immediately from **Dashboard → Scheduled Tasks → Flynn: storage reading** if you do
not want to wait for tonight.

## No third-party plugins needed

Most plugins that draw anything into the Jellyfin web UI depend on **JavaScript Injector** and
**File Transformation**. Neither has a Jellyfin 12 build, which would have made this plugin a
silent no-op on the only servers it targets.

Flynn injects its own client script by rewriting the web UI response as it is served. Nothing is
written to disk, so there is no permissions problem on Docker installs, and nothing to redo after
a server upgrade.

## What it will not do to you

**It changes nothing.** The write level defaults to none, and every module starts read-only. When
that changes, anything touching your files will have to produce an undo manifest *before* it runs,
or it will be refused rather than attempted.

**It will never rename or move a media file.** Folders and sidecar files only. If you seed what
you serve, that matters, and it is a rule rather than an intention.

**Its database lives in the server's data directory**, not in the plugin folder. Jellyfin's own
upgrade guidance tells you to remove plugins before migrating; doing that will not throw away the
history the future capacity forecast is drawn from.

## Known limits

- One module. The foundations underneath are considerably further along than the feature list.
- Library sizes come from what the server has already measured. Files it has not scanned yet count
  towards the item tally but not the bytes, and fill in on the next library scan.
- English and French only.

## Requires

Jellyfin **12.0 or later**. There is no 10.11.x build and there will not be one.
