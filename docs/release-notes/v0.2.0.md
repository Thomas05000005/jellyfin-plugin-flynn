# Flynn v0.2.0

Groups modules by category, and gives the plugin a face of its own.

## Categories

Modules now sit under **Operations**, **System**, **Library**, **Music** and **People**, each with
a count. Storage is under System.

With one module this is barely visible. With fifteen it is the difference between a dashboard and
a wall, which is why it is in before the modules rather than after.

The order is fixed rather than taken from whatever order the server enumerated, so a module
appearing or disappearing never reshuffles the shelves around it. The category is a fixed set, not
a free string, so nothing ends up under both "Library" and "Libraries".

## A look of its own

Cyan for normal, amber for attention, on cards that lift slightly on hover, with the state carried
by a gradient edge and a lit dot rather than a coloured background.

That last part is deliberate. The colours are only ever accents -- edges, dots, the switch --
never the surface text sits on. Hard-coding light text on a dark fill was a real bug class in the
predecessor plugin: it looked right in the default theme and was unreadable in every light one.
Everything structural still comes from Jellyfin's own theme variables.

The hover lift is disabled when the system asks for reduced motion, since it is decoration rather
than information.

## Requires

Jellyfin **12.0 or later**.
