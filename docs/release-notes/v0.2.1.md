# Flynn v0.2.1

Three translation gaps, all visible in the same screenshot.

## The French had no accents

Section labels and state badges read *Degrade*, *Desactive*, *a l'instant*. The module messages
had been fixed earlier; the page's own chrome was added afterwards and reintroduced the same
mistake, because those entries were generated by a script that avoided non-ASCII characters.

The pure-ASCII rule applies to the injected client script, which some Jellyfin clients decode as
latin1. It has never applied to a UTF-8 JSON catalogue, and unaccented French reads as broken to
the people it is for.

## The size unit stayed English

**19,5 TB** — a French decimal comma next to an English unit, out of the same computation. The
number went through the translation layer and the unit did not.

Units are now catalogue entries like everything else, and an argument can itself be translatable,
so the number and its unit are resolved together for the same reader. French gets **19,5 To**.

## Module names and descriptions were literals

*Storage* and *How much your libraries hold* were plain strings on the module contract, so they
stayed English on every server. A module's own name is as user-facing as anything it reports.

## Requires

Jellyfin **12.0 or later**.
