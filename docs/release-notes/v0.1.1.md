# Flynn v0.1.1

Fixes the defect that made v0.1.0 not actually usable.

## Modules were off, with no way to turn them on

Every card showed **Disabled** on a fresh install, and there was no switch anywhere. The plugin
loaded, rendered, and did nothing you could change.

Two things were wrong. A module the admin had never configured fell back to off rather than to its
own default, which contradicted the configuration model's own documented behaviour: an absent
entry means "never asked", not "asked and declined". And the toggle simply did not exist.

Both are fixed. Storage is on by default because it only reads; anything that could write will
start off regardless, since the write level gates it separately.

## The page spoke two languages at once

Card text came from the translation catalogue and followed your browser, while the page's own
chrome -- section titles, state labels, "just now" -- was hard-coded English in the script. So a
French admin saw a French headline under an English label.

Every label now comes from the same catalogue, resolved for the reader in one place.

## Also

The card layout was reworked: a switch and a state dot per module, and disabled cards read as
dimmed rather than as broken.
